# Veille et tendances

## Règles
- Tout ce qui est affirmé a une **source** (lien) et une **date**. Pas de source : c'est une estimation, et on le dit.
- On privilégie le récent : les 30 derniers jours pour une tendance, les 12 derniers mois pour un chiffre.
- On ne recopie jamais une vidéo : on s'inspire du **format** et de l'**angle**, pas du contenu.

## 1. Chercher un sujet (le chercheur)
1. 3 à 5 recherches différentes : le sujet + « chiffres », « étude », « 2026 », « idée reçue », « histoire vraie ».
2. Lire d'abord les sources sérieuses : sites officiels, études, grands médias, Wikipédia pour le contexte (puis ses sources).
3. Recouper : un chiffre surprenant doit apparaître dans **deux** sources indépendantes.
4. Repérer les fausses infos qui circulent sur le sujet (à ne pas reprendre, ou à démonter : ça fait de bonnes vidéos).

## 2. Chercher ce qui marche (le chasseur de tendances)
Requêtes utiles (WebSearch) :
- `tiktok trend <niche> <mois> <année>`, `<niche> viral tiktok`, `site:tiktok.com/@ <niche>`
- `youtube shorts <niche> most viewed`, `site:youtube.com/shorts <niche>`
- `instagram reels trend <mois> <année>`, `trending audio reels <mois>`
- Les pages « Creative Center » de TikTok (hashtags et sons tendance) quand elles sont lisibles.

Pour chaque exemple trouvé, note : le lien, la date, les vues (si visibles), l'**accroche** (la première phrase ou le premier texte à l'écran), le **format**, la durée.

Les formats qui reviennent souvent :
| Format | Quand l'utiliser |
|---|---|
| Liste (« 3 erreurs qui… ») | sujets pratiques, conseils |
| Avant / après | transformation, tutoriel |
| Storytime face caméra | expérience vécue, coulisses |
| Mythe vs réalité | idées reçues, fausses infos |
| POV / mise en situation | humour, situations du quotidien |
| Réaction / duo | actualité, tendance déjà virale |

## 3. Ce qu'on rend
Un fichier `tendances-<niche>.md` ou `recherche-<sujet>.md` :
1. **En bref** : 3 lignes.
2. **Top 10 des idées de vidéos**, classées par potentiel (fort / moyen), avec pour chacune : l'accroche proposée, le format, la durée conseillée, l'exemple qui le prouve (lien + date).
3. **Faits et chiffres** (sourcés) utilisables dans les scripts.
4. **Sons et hashtags du moment** (avec la date du constat : ça change vite).
5. **À éviter** : fausses infos, sujets saturés, risques (droits d'auteur, sujets sensibles).
